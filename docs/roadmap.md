eqSh is a work in progress, and we're always looking for ways to improve it.
Of course it's nowhere near complete, but we're always adding new features to make it a better experience for everyone.

If you're interested in contributing to the project, check out our [Github](https://github.com/eq-desktop/eqsh).

### Roadmap

- [x] Notch  
- [x] Notch Applications  
- [x] Notifications

- [x] App Drawer / Launchpad
- [x] Lockscreen
- [x] Wallpaper Engine
- [x] System Tray
- [x] Battery & WiFi Indicators
- [x] Clock
- [x] On-Screen-Displays for Volume and Brightness
- [x] Polkit
- [x] Control Center
- [x] Dock
- [x] Sigrid AI Chatbot

- [x] Full JSON user settings & Settings App
- [x] Control Center
- [x] Advanced IPC-powered popup system
- [x] Spotlight

- [ ] Dock with magnification
- [ ] Desktop Files
- [ ] Spotlight Extensions
